# Font files for 3D Text

Place your 3D font JSON files in this directory. You need to convert your fonts to JSON format compatible with Three.js.

## How to generate font files:

1. Visit https://gero3.github.io/facetype.js/
2. Upload your font file (e.g., Inter-Bold.ttf)
3. Download the generated JSON file
4. Rename it to `inter_bold.json` and place it in this directory

The minimum font you need is:
- inter_bold.json (for the 3D text elements)

You can generate more fonts if needed for different text styles.
